= ITC-2300 VoIP Labs Router Configurations for PSTN Simulator and Test Pod

== Notes
These configurations allow for the PSTN Simulator to be setup as well as for a VoIPTestPod which has two FXS ports and a T1 connection to allow test calls to be made to/from analog POTS phones into the simulated environment.

You will need to adapt the VoIPTestPod as required with different DIDs depending on what port it is plugged into on the PSTN simulator.

== VoIP Test Pod Router Configuration

----
!
hostname VoIPPod3
!
card type t1 0 1
!
ip domain name campus.ihitc.net
!
isdn switch-type primary-ni
!
voice-card 0/1
 dsp services dspfarm
 no watchdog
!
voice-card 0/2
 no watchdog
!
license accept end user agreement
license boot suite FoundationSuiteK9
license boot level uck9
no license smart enable
!
controller T1 0/1/0
 framing esf
 clock source line primary
 linecode b8zs
 cablelength short 110
 pri-group timeslots 1-24
 description Connection to PSTN
 no shutdown
!
interface Serial0/1/0:23
 description Connection to PSTN
 no ip address
 encapsulation hdlc
 isdn switch-type primary-ni
 isdn incoming-voice voice
 no shutdown
!

 no shutdown
